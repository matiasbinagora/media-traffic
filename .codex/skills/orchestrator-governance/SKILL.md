---
name: orchestrator-governance
description: "Plan scoped work, assign specialist handoffs and coordinate independent technical and functional gates across projects."
---

Read project governance and skill-map first. Resolve outcome, scope, acceptance criteria, dependencies and risks. Use the tracker and spec system actually present; do not impose a board, status sequence or OpenSpec on another repository. Define one accountable owner per task and pass its exact skill names, worktree and validation requirements. Keep implementation with developers; coordinate independent code review and functional acceptance. Preserve authorization boundaries for external writes, merges and closure. Use worktree-task-isolation when assigning isolated work. Report decisions, owner, handoff and pending gates.
