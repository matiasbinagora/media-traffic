---
name: developer-task-execution
description: "Implement an approved, scoped backend or frontend task with relevant tests and an evidence-based handoff."
---

Read the applicable project instructions, task contract, stack and skill-map. Clarify only information that changes correctness. Use git-feature-workflow and worktree-task-isolation before implementation. Load relevant backend/frontend architecture skills, keeping framework-specific guidance conditional. Keep changes scoped and preserve unrelated work. Add meaningful tests for changed behavior and run the checks required by this stack/task; explain valid exceptions. Update relevant specs/contracts when the project uses them. Report exact commands/results, changed files, branch/worktree, limitations and PR when created. Independent review, acceptance, merge and closure remain separate gates.
